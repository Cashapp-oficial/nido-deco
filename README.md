# Nido Muebles y Deco (maqueta)

Landing de una tienda de deco en melamina. Las fotos son de stock (Unsplash) y los productos, precios y datos de contacto son de ejemplo.

Para cambiar el número de WhatsApp, el descuento o los productos, editá el bloque de configuración al principio del `<script>` en `index.html`.
