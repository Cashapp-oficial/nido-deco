# Nido · Deco en melamina (maqueta)

Tienda mínima: portada con 6 productos, ficha de cada producto y checkout. Las fotos son de stock (Unsplash) y los productos, precios y datos de contacto son de ejemplo.

- `index.html`: portada
- `producto.html?id=1`: ficha de producto
- `checkout.html`: carrito y finalizar compra (no cobra: el pedido se manda por WhatsApp)
- `tienda.js`: productos, precios, WhatsApp, descuento y envío. Todo lo que se cambia está ahí.
- `img/pN-1.jpg` a `pN-3.jpg`: las 3 fotos de cada producto
